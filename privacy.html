プライバシーポリシー

制定日：2026年10月28日

Vぶい（以下「本サービス」）の運営者（以下「運営者」）は、本サービスをご利用いただく方（以下「利用者」）の情報を、以下のとおり取り扱います。

1. 本サービスについて

本サービスは、デビューして間もない個人勢VTuberの配信を見つけ、応援するためのウェブサイトです（https://vvbuibui.com）。

2. 取得する情報

(1) YouTubeで公開されている情報
本サービスは、YouTube API サービスを利用して、YouTubeで一般公開されているチャンネル情報（チャンネル名、アイコン画像、概要欄、登録者数、動画・配信のタイトル、サムネイル、配信日時、視聴者数など）を取得し、名鑑や配信一覧として表示します。非公開の情報は取得しません。

(2) 本人登録の際に取得する情報
VTuber本人が「YouTubeのアカウントで本人登録」を行った場合、Googleアカウントでのログインを通じて、次の情報を取得します。

  • Googleアカウントのメールアドレス、名前、プロフィール画像（ログインの識別のため）
  • YouTubeアカウントの表示権限（youtube.readonly）を使って取得する、ログインしたアカウントが所有するYouTubeチャンネルのID・チャンネル名・アイコン画像・公開されている統計情報

YouTubeアカウントの表示権限は、本人登録の手続き中に、ログインした方がどのチャンネルの所有者かを確認するためだけに1回使います。この権限で、動画の投稿・削除、コメント、設定の変更などを行うことはできず、行いません。また、Googleから受け取るアクセス用の情報（アクセストークン）は保存しません。

(3) 本人が入力する情報
本人登録後に設定画面で入力された、コラボ募集の有無、得意なジャンル、XのID。

(4) 利用状況の情報
ページの閲覧やボタンの操作などの利用状況を、個人を特定しない端末ごとの識別子とあわせて記録することがあります。また、推しリストなどの設定は、利用者の端末のブラウザ内（ローカルストレージ）に保存されます。

3. 利用目的

  • 本サービスで、新人VTuberのチャンネルや配信を紹介するため
  • 本人登録を行ったVTuberが、そのチャンネルの所有者であることを確認するため
  • 本人登録したVTuber向けの機能（本人登録バッジ、配信一覧での上位表示、同期ランキング、コラボ相手さがし、配信開始の告知など）を提供するため
  • 本サービスの改善、不正利用の防止、お問い合わせへの対応のため

4. Googleユーザーデータの取り扱い

本サービスがGoogle APIから受け取った情報の利用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

Googleから受け取った情報を、広告の配信、販売、上記の利用目的以外のために使うことはありません。

5. 第三者への提供

運営者は、法令に基づく場合を除き、利用者の同意なく個人情報を第三者に提供しません。なお、本人登録したチャンネルについては、チャンネル名・アイコン画像・本人登録済みであること・入力されたXのIDやジャンルが、本サービス上で公開されます。

6. 外部サービスの利用

本サービスは、次の外部サービスを利用しています。

  • YouTube API サービス：本サービスはYouTube API サービスを利用しています。利用者は本サービスを利用することで、YouTube 利用規約に同意したものとみなされます。Googleによる情報の取り扱いは、Google プライバシーポリシーをご確認ください。
  • Supabase：データの保存と、ログインの仕組みに利用しています。
  • GitHub Pages、Cloudflare：ウェブサイトの公開に利用しています。

7. 保存期間と削除

  • 本人登録の情報は、本人登録が解除されるまで保存します。マイページの「本人登録を解除する」から、いつでも解除できます。
  • Googleアカウントの サードパーティ製のアプリとサービス から、本サービスへのアクセス権をいつでも取り消せます。
  • ログイン情報を含むすべての情報の削除、または名鑑への掲載の停止を希望される場合は、下記のお問い合わせ先までご連絡ください。確認のうえ、すみやかに削除します。

8. 安全管理

運営者は、取得した情報の漏えい、紛失、改ざんを防ぐため、アクセス制限など適切な安全管理を行います。

9. このポリシーの変更

内容を変更する場合は、このページでお知らせします。
